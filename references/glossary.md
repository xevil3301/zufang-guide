# 术语表

- **押一付三**：交一个月租金作为押金，一次性预付三个月租金。押金在退租验收后返还。
- **二房东**：从原房东处整租后再转租的人。无原房东书面同意时转租可能无效，且存在卷款跑路风险。
- **转租**：承租人在租期内把房屋再租给第三人。需合同允许或房东书面同意，建议三方签字。
- **租售一体条款**：合同中约定房东出售房屋时可要求租客提前搬离。指南明确不建议签。
- **居住权**：民法典规定的用益物权；房屋设立居住权后不得再出租，租房前应确认。
- **定金 / 订金**：定金具有担保性质，违约方可能丧失或双倍返还；订金一般视为预付款。看房前不支付任何费用。
- **租赁备案 / 居住登记**：部分城市要求出租房屋备案并登记租客信息，影响居住证与子女入学等权益。
- **押金托管**：部分城市推行的押金监管制度，退租时按验收结果划转。
- **交接单**：入住/退房时记录房屋与家电状况、水电表底数的清单，一式两份双方签字。
- **隐形费用**：租金之外未提前说明的费用，如卫生费、治安费、公摊水电、网费、取暖费。
- **买卖不破租赁**：房屋所有权变更不影响已生效的租赁合同，新业主承继原合同。
- **12315 / 12345 / 96119 / 12348 / 12366**：分别为市场监管投诉、政务服务热线、消防举报、法律援助热线、税务举报。
