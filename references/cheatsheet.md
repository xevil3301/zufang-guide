# 决策规则速查 — 《城市租房生存指南》

| 能力 | 一句话规则 |
|---|---|
| 先问诊后开方 | 六槽位（地点/钱/时间/阶段/对方/目标）先抽后问，每轮 ≤5 问、每问带理由，三轮内收敛。 |
| 预算与需求定位 | 先用可支配余额算出租金上限（见 affordability-model），再按通勤、房型、设施、周边五项排优先级。 |
| 租金负担能力测算 | 租金上限 = min（收入 − 刚性支出 − 储蓄 − 缓冲，档位比例上限）；月入 3–5k 超过 30% 即不合理。 |
| 找房渠道与真假甄别 | 官方备案平台优先，看房前不交钱，核对房产证+身份证，低价房源先当骗局验。 |
| 看房体检清单 | 白天带人、先看小区再验门窗水电结构，逐项拍照，费用与维修责任当场问清。 |
| 合同审查与谈判 | 先验房东身份与产权，再逐条审 8 项必备条款，5 类陷阱条款逐条改写后再签。 |
| 入住交接与安顿 | 入住 72 小时内完成「拍照交接—深度清洁—开通水电燃气网络—居住登记」四件事。 |
| 日常维护与沟通 | 报修先文字留痕、不擅自拆改、合租先立规则，所有约定落成文字。 |
| 退租与押金回收 | 提前一个月书面通知，清场复原并结清费用，约房东现场验收后签退租协议再拿押金。 |
| 转租操作 | 先查合同与房东书面同意，再找接手人、签三方协议、结清费用并现场交接。 |
| 维权、补贴与公积金 | 维权按协商→调解→12315/房管/住建→12348→诉讼升级；补贴与公积金先查当地政策再备材料。 |
| 居家安全加固 | 先解决门（阻门器/门磁/可视门铃），再补隐私（快递单）与应急（手电/报警器），预算 300 元内可配齐基础项。 |
| 法律依据速查 | 押金看条例第10条、转租看民法典716/718、维修看712/713、买卖不破租赁看725、隔断房看条例第7条。 |
| 短租与过渡住房 | 短租也要写清起止日与押金收据；不写期限就是随时可被清退的不定期租赁。 |
| 租金贷、年付与资金监管 | 看到《分期服务协议》就当租金贷处理；只接受房东本人 + 可查产权 + 监管账户的年付。 |
| 城市公共服务与凭证 | 先备案再登记，再办学位/公积金/补贴；材料一次备齐、复印三份。 |
| 场景分诊与兜底动作 | 三问定位（签没签/钱还是安全/判断还是办事）→ 场景表取主卡 → 未命中走法条+12348/12345/110。 |
| 城市参数卡 | 六参数逐项核（居住证/学位/公积金/短租/监管/50% 线），已核实写值、未核实标「需现查」并给入口。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
