# 租金负担能力测算（可支配余额法）


> 本卡是对原书「房租不超过月收入 1/3」口径的**扩展**，不是原书原文。原书只给了单一比例，没有处理低收入、负债与未来计划；本卡用「可支配余额 + 分档上限 + 未来计划折现」替代拍脑袋的比例。


## 必答要点（先看这 6 行）

- 上限 = min（收入 − 刚性支出 − 储蓄 − 缓冲，收入 × 档位上限）
- 必须同时给：绝对上限、推荐值、与报价的差额
- 月入 3–5k：30% 是红线，推荐 25%；超过即不合理

> 回答末尾必须逐条复述以上要点（已覆盖 / 不适用+原因），缺一条视为未完成。

## R — 原文 (Reading)

> "一般来说，房租最好别超过你月收入的三分之一，这样才能保证你还有钱吃饭、穿衣、娱乐啥的。"
> — 《城市租房生存指南》§1.1.1（本卡以此为起点，下文为扩展模型）

## I — 方法论骨架 (Interpretation)

房租合不合理，不由市场均价决定，而由「交完房租后还剩多少、这些钱够不够支撑你未来 12–24 个月的计划」决定。三步：第一步，把收入拆成刚性支出（吃饭、通勤、通讯、保险、还贷、赡养），得到生活基线；第二步，把未来计划折成每月要存的钱（存 3 万 / 24 个月 = 1250 元/月），再加上应急缓冲；第三步，用「收入 − 基线 − 储蓄 − 缓冲」算出真实可承受的房租 A，再用收入档位的比例上限校验一次，取两者较小值。比例上限不是目标，是红线：收入越低，食品、医疗、通勤这些不可压缩项占比越高，30% 就已经偏紧；收入越高，比例可以略高，但仍要让位于储蓄目标。市场价高于 A，说明这个地区对这个收入不合理，选项只有四个：合租、换区域、换城市、提高收入——而不是压缩吃饭和保险去凑房租。

## A1 — 应用示例

### 示例 1：月入 4500，房租 1500 是否合理
- **类型与来源**：合成演练（按本卡公式计算；原书只给 1/3 口径）。
- **输入**：税后 4500；餐饮 1200、通勤 200、通讯 100、日用品 200、保险 100；无负债；未来 24 个月想存 2 万。
- **方法论的使用**：基线 L = 1800；储蓄 S = 20000 ÷ 24 ≈ 833；缓冲 B = 4500 × 8% = 360；A_raw = 4500 − 1800 − 833 − 360 = **1507**；档位上限（3000–5000 档，取 25–30%）→ 上限 1350，推荐 1125；取较小值：**A ≈ 1350（上限）/ 1125（推荐）**。
- **结论**：1500 元占收入 33.3%，超过该档上限，且会把储蓄压到 0 以下——**不合理**。要么压到 1250 以内，要么合租把房租降到 900–1100。
- **结果**：合成演练，无现实成交；公式可复算。

### 示例 2：月入 12000，但有负债与读研计划
- **类型与来源**：合成演练。
- **输入**：税后 12000；餐饮 1800、通勤 300、通讯 100、日用 300、保险 200、助学贷款 1500；计划 18 个月后读研，需存 4 万。
- **方法论的使用**：L = 4200；S = 40000 ÷ 18 ≈ 2222；B = 960；A_raw = 12000 − 4200 − 2222 − 960 = **4618**；档位上限（8000–15000 档 30–35%）= 4200；取较小值 **A = 4200**。
- **结论**：租金 4200 以内合理；若市场价 5000，需把储蓄目标下调、延长存钱周期，或选择合租/远郊，而不是取消保险或停还贷款。
- **结果**：合成演练。

## A2 — 触发场景 (Future Trigger)

### 用户会在什么情境下需要这个 skill?

1. 问「这个房租合不合理」「我这收入能租多少钱」。
2. 所在地工资 4–5k，房租却要 1500–2000，怀疑被市场绑架。
3. 有明确计划（存钱、读研、换城市、结婚），需要在房租和储蓄之间取舍。

### 语言信号

- "房租占收入多少合理" / "这个价格是不是太贵"
- "我月入 4500 能租 1500 吗" / "还要存钱"
- "rent affordability" / "how much rent can I afford"

### 与相邻能力的区分

- 与 `budget-and-needs` 的区别：那张卡回答「预算怎么定、房型怎么选」，本卡回答「这个价格对你是否合理」，给公式与判定。
- 与 `rights-and-benefits` 的区别：本卡是决策前的测算，不处理纠纷。

## E — 可执行步骤 (Execution)

**必需输入**：税后月收入（波动收入取近 6 个月最低值）、刚性支出明细、负债月供、未来 12–24 个月的计划与所需金额、现有现金。缺收入或计划时先问，不套模板。

**交付物与完成标准**：一张测算表（收入 / 基线 / 储蓄 / 缓冲 / A_raw / 档位上限 / 最终上限）+ 一句判定（合理 / 偏高 / 不合理）+ 备选方案。

1. **算生活基线 L**
   - 完成标准：列出餐饮、通勤、通讯、日用品、保险医疗、还贷、赡养七项，给出合计；不含房租与娱乐。
2. **算储蓄 S 与缓冲 B**
   - 完成标准：S = 目标金额 ÷ 月数；B = 收入 × 8%（收入波动大时取 10%）。
3. **算 A_raw 并校验档位**
   - 完成标准：A_raw = 收入 − L − S − B；再用档位表取上限，最终 A = min(A_raw, 档位上限)。
   - **必须同时给出三个数**：绝对上限（档位上界）、**推荐值（收入 × 推荐区间下界，如 4500×25% = 1125）**、当前报价与两者的差额。只给一个上限视为未完成。
4. **判定**
   - 完成标准：市场价 ≤ A → 合理；A < 市场价 ≤ 档位上限 → 偏高，需压储蓄或合租；市场价 > 档位上限 → 不合理，给四个选项（合租/换区域/换城市/提高收入）。
5. **未来计划折现**
   - 完成标准：按计划调整储蓄权重与合同期限（见下表）。
   - 判停条件：A ≤ 0 → 直接判定「该收入无法独立承担该区域整租」，不再讨论房源。

### 收入档位红线（占税后收入）

| 税后月收入 | 绝对上限 | 推荐区间 | 说明 |
|---|---|---|---|
| < 3000 | 25% | 20–25% | 食品与医疗不可压，超过即风险 |
| 3000–5000 | 30% | 25–28% | 30% 是红线，超过就没有储蓄空间 |
| 5000–8000 | 30% | ≤30% | 用 A_raw 校验，别只看比例 |
| 8000–15000 | 35% | 30–33% | 有储蓄目标时压到 30% 以内 |
| > 15000 | 35% | 视目标 | 比例让位于储蓄与投资目标 |

### 未来计划 → 租金与合同

| 计划（12–24 个月） | 对租金的影响 | 合同建议 |
|---|---|---|
| 换城市 / 换工作 | 压到推荐区间下界，预留 1 个月空置 | 押一付一、6–12 个月、写明可转租 |
| 存钱目标（结婚/留学/首付） | S 提高，房租上限下降 | 合租或远郊，签 12 个月 |
| 收入将上升（试用期/跳槽） | 不按预期收入定租，最多按现收入 +10% | 先短租过渡 |
| 可能同居/结婚 | 保留退出灵活性 | 不签 2 年，违约金 ≤1 个月租金 |
| 考研/进修 | 收入可能中断 | 预留 6 个月房租现金 |

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 公司/学校提供住房、房租由单位承担：负担能力不是约束。
- 已有明确投资性购房计划：属于资产配置，不是租房预算。
- 用预期收入（还没到手的 offer）做测算：只能用已到账收入。

### 常见误用

- 拿「市场价就这样」反推合理：市场价只说明供给，不说明你可承受。
- 只看比例不看余额：月入 4500 的 30%（1350）与月入 15000 的 30%（4500）完全不是一回事。
- 把应急缓冲砍掉去凑房租：一次失业或生病就会违约。

### 盲点 / 局限

- 不预测收入增长、行业波动与城市租金走势；这些须用户自己判断。
- 不替代记账：刚性支出需要真实数据，拍脑袋填会得出错的 A。
- 不构成理财建议；储蓄目标由用户设定。
