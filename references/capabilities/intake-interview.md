# 先问诊后开方（intake-interview）

> 用法：当用户只给了一句模糊的话（「押金不退」「想租房」「合同靠谱吗」），先用这张卡把拼图问齐，再回答。**信息不足时给通用答案，比不答更糟。**

## 硬规则（首轮只发问题）

首轮回复的结构固定为两段，多一段都算违规：

1. 一句「为什么现在还不能答」（点明缺哪个槽位、它会影响什么结论）。
2. **3–5 个问题**，每个问题带「为什么问」+ 2–4 个选项。

首轮**禁止**出现：结论段、操作步骤、金额/比例、法条清单、处理路径。用户答完（或明确说「先给大概」）之后，才进入正常作答。

## I — 方法论骨架 (Interpretation)

租房问题的答案高度依赖六个变量，缺一个就会答错方向：**在哪（城市+区）、有多少钱（收入/刚性支出/现金）、什么时间（入住/住多久/未来计划）、到哪一步（签没签/付没付/有无证据）、对面是谁（房东/二房东/中介/公寓/平台）、要什么（省钱/稳定/维权/办事）**。问诊不是问卷，是「按影响排序、每轮只问会改变结论的问题」：先问分叉最大的（地点、到哪一步、目标），再问金额与时间；每问都告诉用户「为什么问、答了会改变什么」，并给可选项降低回答成本。用户答不上来时给保守默认值并标注假设，而不是无限追问。三轮之内必须收敛：要么信息够了给结论，要么带着假设给结论并说明「补哪条信息会改变什么」。

## A1 — 应用示例

### 示例 1：一句「押金不退」
- **类型与来源**：合成演练。
- **输入**：用户只发「房东不退押金，怎么办」，没有城市、金额、证据、阶段。
- **方法论的使用**：抽槽位——地点 ✗、金额 ✗、阶段 ✗、对方 ✗（可能是房东）、目标 ✓（拿回钱）。按影响排序问 4 个：① 哪个城市/区（决定投诉渠道与是否小额诉讼）；② 合同和转账还在吗、有没有入住照片（决定举证）；③ 押金多少、房东以什么理由扣（决定走协商还是诉讼）；④ 房东是本人还是二房东（决定能否找原房东/平台）。
- **结论**：四问答完再给「协商话术 → 12315/住建 → 小额诉讼」的路径；未答的项用默认值并标注。
- **结果**：合成演练。

## A2 — 触发场景 (Future Trigger)

### 用户会在什么情境下需要这个 skill?

1. 第一句话信息极少：「被坑了」「合同有问题」「想租房」。
2. 问题跨城市政策，但没说城市。
3. 用户自己也没想清楚要什么（省钱？稳定？维权？）。

### 语言信号

- "怎么办" / "靠谱吗" / "帮我看看"（无上下文）
- 没有城市、没有金额、没有时间
- "随便"/"都行"/"你看着办"

### 与相邻能力的区分

- 与 `triage` 的区别：triage 决定「读哪张卡」，本卡决定「还缺哪些事实、怎么问出来」。
- 与 `city-params` 的区别：本卡负责问出城市与区，城市卡负责查该城市的六参数。

## E — 可执行步骤 (Execution)

**必需输入**：用户原话。其余全部靠问。

**交付物与完成标准**：第一轮输出「一句判断 + ≤5 个问题（每个带为什么问 + 选项）」；信息齐后输出「结论 + 依据 + 假设清单 + 下一步」。

1. **抽槽位**
   - 完成标准：把原话填进六槽（地点/钱/时间/阶段/对方/目标），标出 ✓ 与 ✗。
2. **排影响**
   - 完成标准：按「地点 > 阶段 > 目标 > 金额 > 时间」排序，只问前 3–5 个缺口。
3. **发问（固定模板，已知跳过）**
   - 首轮就按这五问的顺序发，缺哪个问哪个，总数不超过 5：
     1. 你在**哪个城市、哪个区**？（决定政策、学位、投诉渠道与小額诉讼线）
     2. 现在**走到哪一步**：还没签 / 签了没付 / 付了没住 / 已入住 / 已退租？
     3. 手里**有什么**：合同、转账记录、聊天记录、照片/视频？（决定能不能举证）
     4. 对面**是谁**：房东本人 / 二房东 / 中介 / 长租公寓 / 平台？
     5. 你最想**解决什么**：省钱 / 稳定住下去 / 把钱拿回来 / 办事（居住证、学位、公积金）？
   - 场景追问优先用下方「场景问询树」里对应的一棵，不再临时发挥。
   - 完成标准：五问覆盖地点、阶段、证据、对方、目标；每问带「为什么问」+ 选项；总数 ≤5。
   - **硬门**：首轮回复里只要出现结论、步骤、金额或法条清单，即判为未按本卡执行。
4. **收敛**
   - 完成标准：用户答完回填；仍缺 → 第二轮（累计 ≤3 轮）；用户说不知道 → 用保守默认值并标注。
   - 判停条件：涉及人身安全 → 先问「现在安全吗」，必要时直接给 110，不等其他信息。

### 六槽位与默认值

| 槽位 | 问什么 | 用户不知道时的默认 |
|---|---|---|
| 地点 | 城市 + 区 | 按「全国通用规则 + 需现查」作答，不给具体金额 |
| 钱 | 税后收入、刚性支出、可动现金 | 按当地中位数假设并标注 |
| 时间 | 入住时间、租期、12–24 个月计划 | 按 12 个月、无迁移计划 |
| 阶段 | 签没签、付没付、有无合同/转账/照片 | 按「未签未付」给预防建议，并补「已付怎么办」 |
| 对方 | 房东/二房东/中介/公寓/平台 | 按房东本人处理，提示二房东风险 |
| 目标 | 省钱/稳定/维权/办事 | 按「先止损再省钱」处理 |

### 话术规范（参考 khazix 的「活人感」，只借语气不借文体）

- 说人话，短句，像朋友先问一句，不写公文腔（不要「请您提供以下信息」）。
- 每问先给一句**为什么问**（≤20 字），再给 2–4 个选项，让人能用一句话回答。
- 涉及钱和隐私，明确说「大概就行、给区间也可以」，降低回答压力。
- 一次只问 3–5 个，最影响结论的排第一；用户答「不知道」就给默认值让他确认（「那我先按 X 算」），不追同一题。
- 不重复问已经说过的信息；不用连环问号，一题一个问号。
- 语气示例：「你公积金账户里大概趴着多少钱？这个数决定你能抵多少房租，给个区间就行。」

### 场景问询树（首轮最多 4 问，第 5 项留到二轮）

**首轮上限是 4 个问题**——第 5 项及以后一律等用户答完再问。树里标「二轮」的不要放进第一条回复。

**A. 公积金抵房租**
1. 城市 + 区（额度、频次按城市）
2. 账户余额大概多少（决定能抵多少）
3. 每月缴存多少、连续缴了多久（是否满足 3/6 个月门槛）
4. 本人及配偶在当地有房吗（无房才可租房提取）
5. 有租赁合同/备案吗、以前提取过吗（二轮再问）
二轮：想按月还是按季提；是否已婚（配偶额度是否合并）。
停：余额明显低于年租金 → 直接给「覆盖不了，需要补现金」的结论。

**B. 押金不退**
1. 城市 + 区
2. 押金多少、房东以什么理由扣（墙面/清洁/违约）
3. 手里有什么：合同、转账、聊天、照片/交接单
4. 对方是谁：房东本人/二房东/中介/长租公寓
5. 走到哪一步：还在协商/已投诉/已搬走
二轮：合同里押金条款怎么写的；有没有入住照片。

**C. 预算与找房**
1. 城市 + 区
2. 税后月收入
3. 每月固定支出（还贷、赡养、保险）
4. 能一次拿出的现金（押付 + 中介 + 搬家）
5. 几个人住、通勤目的地与上限、打算住多久
二轮：接不接受合租；要不要独立卫浴；有没有宠物。

**D. 合同审查**
1. 把合同关键页发我（租金、押金、租期、违约、维修五段）
2. 城市
3. 租期与押付方式
4. 对方是谁（房东/二房东/中介）
5. 定金或租金付了没有
二轮：涨租、提前解约、退房结算条款原文。

**E. 孩子学位**
1. 城市 + 区
2. 孩子年龄 / 入学年份
3. 社保连续缴了几年
4. 居住证状态：没有 / 登记中 / 已拿证
5. 租赁备案了吗、户籍在哪
二轮：目标学校有没有学位预警；接不接受统筹。

**F. 短租过渡**
1. 城市 + 区
2. 起止日期（精确到日）
3. 预算与支付方式
4. 接不接受合租或服务式公寓
二轮：要不要发票/备案。
停：少于 7 天 → 直接建议酒店/民宿，不签租赁合同。

### 案件卡（每轮末尾带一行，用户能看懂）

目的：把你已经告诉我的信息记下来，方便你核对，也避免我重复问。

格式（一行，信息少的项写「待确认」）：

```
【案件卡】城市：待确认 ｜ 阶段：已交押金 ｜ 证据：合同+转账 ｜ 对方：房东 ｜ 目标：拿回押金 ｜ 金额：3000
```

对用户的说辞（照这个语气说，不要用术语）：

> 我在末尾放一张小卡片，把你刚说的信息记下来，你扫一眼就能看出我有没有记错；有错直接说，我改。

规则：
1. 每轮回复末尾更新这张卡，只写已确认的信息；
2. 下一轮只问「待确认」的项，不重复问已答项；
3. 用户说「别弄这个」→ 立刻停用，改为纯对话。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 用户已经给全六槽：直接答，不要为了走流程再问一遍。
- 用户明确说「先给我个大概」：给区间 + 变量说明，不硬问。

### 常见误用

- 一次问十个问题：用户会放弃。
- 问已知信息：显得没读消息。
- 缺城市却给具体租金/补贴数字：等于编造。
- 把问诊做成无限追问：三轮必须收敛。

### 盲点 / 局限

- 问诊依赖用户耐心；对只想快速得到方向的用户，应降级为「给区间 + 标注变量」。
- 六槽之外的极端情况（涉外、继承、刑事）仍需 triage 兜底。
