# 转租操作


## 必答要点（先看这 6 行）

- 转租需房东书面同意（民法典 716；商品办法 11）
- 未经同意转租，房东可解除合同（716 第二款）
- 次承租人可代付租金与违约金（719）
- 转租期限不得超过剩余租期（717）；三方签字（3.2.4）
- 转租经营需资金监管（条例 19、20）

> 回答末尾必须逐条复述以上要点（已覆盖 / 不适用+原因），缺一条视为未完成。

## R — 原文 (Reading)

> "二房东转租必须经过原房主的同意，否则合同无效。……三方签字：你、新租客和房东都要在协议上签字，确保三方的权益都得到保障。"
> — 《城市租房生存指南》§1.4.1 / §3.2.4

## I — 方法论骨架 (Interpretation)

转租不是「把房子再租给别人」这么简单，它是一次三方权利重组：原承租人、新承租人、房东。合法性来自两处——合同里允许转租，或房东书面同意；缺一不可，否则转租合同可能无效，原承租人仍要对房东负责。操作顺序：查合同条款 → 与房东沟通并取得书面同意 → 找接手人（朋友圈、小红书、豆瓣、闲鱼、本地超话）→ 筛选（职业、作息、是否接受现状）→ 签三方协议（租金、押金、水电、损坏责任、期限）→ 结清费用、现场验收、交接钥匙、退押金。提前 2–3 个月启动，房东不同意时协商解约或寻找「换租」方案，而不是硬转。

## A1 — 应用示例

### 示例 1：工作调动，还剩 7 个月租期
- **类型与来源**：原书未提供完整案例，以下为按 §3.2 做的合成演练。
- **输入**：合同剩 7 个月，合同未写转租条款，房东在外地。
- **方法论的使用**：① 书面询问房东是否同意转租并请其提供身份证照片用于核验；② 房东同意后，发布转租信息（照片、租金、押金、起租日、周边）；③ 面试两位接手人，选有稳定工作的一位；④ 签三方协议，写明押金由新租客支付给原承租人、房东确认；⑤ 约房东视频参与交接。
- **结论**：三方签字完成，原承租人拿回押金，房东直接向新租客收租。
- **结果**：合成演练；「必须房东同意 + 三方签字」与原书一致。

## A2 — 触发场景 (Future Trigger)

### 用户会在什么情境下需要这个 skill?

1. 工作调动/换城市，租期未到需要找人接手。
2. 房东口头同意转租，但不肯签字或出面。
3. 别人要转租给你，你想确认这个转租是否合法。

### 语言信号

- "我要转租" / "转租合法吗"
- "房东不同意转租" / "转租协议怎么写"
- "sublet" / "take over my lease"

### 与相邻能力的区分

- 与 `contract-review` 的区别：本卡处理已签合同的后续变更，合同卡处理初次签约。
- 与 `deposit-and-move-out` 的区别：转租是「找人接盘」，退租是「结束关系」；转租成功时押金由新租客承接。

## E — 可执行步骤 (Execution)

**必需输入**：原合同转租条款、剩余租期、押金金额、房东联系方式与态度、房屋现状照片。

**交付物与完成标准**：一份转租方案（含合法性判断）+ 三方协议文本 + 交接清单。

1. **判合法性**
   - 完成标准：确认合同允许转租或取得房东书面同意；两者皆无时明确告知风险，不推进。
2. **找接手人**
   - 完成标准：至少 2 个渠道发布，信息含照片、租金、押金、起租日、周边；筛选标准写明。
3. **签三方协议**
   - 完成标准：租金/押金/水电/损坏责任/期限/退租条件写清，三方签字，各留一份。
4. **交接结算**
   - 完成标准：抄表、结清费用、验收房屋、交接钥匙、退还或转移押金，全程留痕。
   - 判停条件：房东明确不同意且合同禁止转租 → 停止转租，改为协商解约，避免违约。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 房东明确不同意且合同禁止：不要私下转租，可能构成违约并承担赔偿责任。
- 想赚差价（低租高转）：属于二房东行为，需房东同意且涉及资质与税务，风险极高。

### 作者在书中警告的失败模式

- 未经房东同意的转租，合同可能无效，原承租人仍需担责。
- 转租协议只写租金不写损坏责任，退租时互相推诿。
- 不结清水电就交接，欠费留在原承租人头上。

### 作者的盲点 / 时代局限

- 未涉及「长租公寓/二房东」场景下的转租合规与资金监管。
- 未讨论转租期间的居住登记与备案变更。

### 容易混淆的邻近方法论

- 与「二手交易」不同：房屋转租涉及合同权利义务概括转移，不能只当成信息发布。

## 法规依据（补充）

- **民法典 716**：经出租人同意可以转租；未经同意转租，出租人可以解除合同。转租后原租赁合同继续有效，第三人造成损失由承租人赔偿。
- **民法典 717**：转租期限超过承租人剩余租期的，超过部分对出租人没有约束力（另有约定除外）——转租不能「超期转」。
- **民法典 718**：出租人知道或应当知道转租，6 个月内未提出异议，视为同意——但这是兜底，不要拿它当策略。
- **民法典 719**：承租人欠租时，次承租人可代付租金与违约金，并充抵其应付租金。
- **《住房租赁条例》第 19、20 条**：转租经营的企业须设住房租赁资金监管账户；自然人转租达到规定规模，适用企业规定。
- **《商品房屋租赁管理办法》第 11 条**：转租应经出租人**书面**同意；未经书面同意转租，出租人可解除合同、收回房屋并索赔。
