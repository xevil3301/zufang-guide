# 维权、补贴与公积金


## 必答要点（先看这 6 行）

- 顺序：协商 → 调解 → 12315/住建/12345 → 12348 → 诉讼
- 起诉四件套：管辖 / 3 年时效 / 50% 线 / 证据，用表格输出
- 非居住空间出租罚 2000–1 万（条例 39）；虚假房源罚 2–10 万（42）

> 回答末尾必须逐条复述以上要点（已覆盖 / 不适用+原因），缺一条视为未完成。

## R — 原文 (Reading)

> "上工商局网站，实名投诉举报黑中介，还可以打 12315 电话投诉。……打 12345 举报违建房（尤其是隔断房），打 96119 消防热线举报消防不合格的房子。"
> — 《城市租房生存指南》§2.4.6

## I — 方法论骨架 (Interpretation)

维权是「按成本从低到高升级」的流程，而不是一上来就起诉：先协商（文字留痕）→ 社区/居委会/人民调解委员会调解 → 政府渠道（市场监管 12315、房管/住建部门、12345 政务热线、96119 消防、12366 税务）→ 法律援助（12348）→ 法院诉讼。每一步都要求三样东西：事实、证据（合同、转账、聊天、照片）、明确诉求。补贴与公积金是另一条「把政策用足」的线：应届生租房补贴按城市政策（如南京博士 2000/月、深圳本科 6000 元、杭州毕业后 2 年内申请），公积金租房提取需租赁合同 + 正常缴存 + 当地额度限制。两者都要先查当地最新政策，再备材料，不能凭旧攻略。

## E — 可执行步骤 (Execution)

**必需输入**：争议事实、合同/转账/聊天记录、对方主体信息（公司名/房东姓名）、所在城市、身份（是否应届/是否缴公积金）。

**交付物与完成标准**：一份「诉求 + 证据清单 + 渠道顺序 + 话术」的行动表；补贴/公积金场景另附材料清单与办理入口。

1. **固定诉求与证据**
   - 完成标准：一句话诉求（退款/维修/解约/赔偿）+ 证据编号清单。
2. **按顺序升级**
   - 完成标准：协商（书面）→ 调解 → 12315/房管/住建/12345 → 12348 → 诉讼，每步写明时限与预期。
   - **提到起诉时必须四件齐备**：管辖法院（房屋所在地/被告住所地）、诉讼时效起算点（3 年，民法典 188）、标的额是否落在小额诉讼线内（165 条：50% 以下 → 一审终审；给出「是/否 + 理由」）、证据清单。缺一项视为未完成。
3. **举报违法违规**
   - 完成标准：隔断/违建 → 12345；消防 → 96119；偷税漏税 → 12366；黑中介 → 12315 + 住建委。
4. **补贴与公积金**
   - 完成标准：给出「当地政策查询入口 + 申请条件 + 材料清单 + 时限」，并注明政策以最新公告为准。
   - 判停条件：涉及人身威胁 → 先报警 110，再走民事渠道。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 需要正式法律意见、代理诉讼或出具鉴定：只能转 12348/律师，不自行下法律结论。
- 单纯想「出口气」而无证据：先补证据，否则投诉难以立案。

### 作者在书中警告的失败模式

- 忍气吞声，错过投诉时效。
- 只口头沟通，无书面证据。
- 相信「包退押金」的中介承诺而不写进合同。

### 作者的盲点 / 时代局限

- 补贴金额与条件按 2024 年前后政策列举，城市政策每年变化，必须现查。
- 未涉及劳动仲裁/刑事报案与民事的边界，也未讨论网络平台投诉的实际处理时效。

### 容易混淆的邻近方法论

- 与「消费者维权」重叠但不同：租赁纠纷同时受民法典合同编与地方租赁管理办法约束。

## 法规依据与城市口径（补充）

### 纠纷解决的法律路径

- **《住房租赁条例》第 35 条**：押金返还、维修、腾退纠纷，先协商；协商不成可申请调解、仲裁或提起诉讼。
- **第 12 条**：解除合同须通知并留合理腾退时间；暴力、威胁逼退可报警并追究责任。
- **第 26 条**：经纪机构应明码标价，**不得在标价之外加价或收取未予标明的费用**——中介临时加收「服务费/加急费/过户费」可直接拒付并投诉。
- **第 39 条**：把厨房、卫生间、阳台、过道、地下储藏室、车库单独出租居住，或个人违反人均面积标准，责令改正 + 警告，拒不改正个人罚 2000–10000 元，有违法所得没收。
- **第 42 条**：住房租赁企业/经纪机构发布虚假房源，罚 2 万–10 万元，情节严重可吊销营业执照。
- **第 43、44 条**：转租企业未设资金监管账户、经纪机构代收代付租金押金，罚 2 万–10 万元。

> 条号别混：**非居住空间出租**用第 39 条（个人 2000–1 万）；**虚假房源**用第 42 条（2 万–10 万）；**代收代付**用第 43/44 条。

- **《民事诉讼法》第 165 条（小额诉讼）**：标的额为各省上年度就业人员年平均工资 **50% 以下**的简单金钱给付案件，适用小额诉讼程序、**一审终审**；50%–2 倍之间，双方可约定适用。押金几千元的纠纷通常落在这一档（多数省份 50% 线在 4–6 万元），**3000 元押金直接符合**。
- **《民法典》第 188 条（诉讼时效）**：普通诉讼时效 **3 年**，从知道或应当知道权利受损及义务人之日起算。

### 南京高校毕业生租房补贴（2026 年口径）

- 标准：**博士 2000 元/月、硕士 800 元/月、学士（含高级工及以上）600 元/月**，累计发放不超过 **36 个月**；2026 年新政将大专生纳入（以最新公告为准）。
- 常见材料：身份证、毕业证/学位证、劳动合同、社保缴纳记录、租赁合同与房屋信息（不动产单元号/丘权号）、本人银行卡；部分材料由系统比对。
- 入口：南京市人社局官网/“宁满意”类政务入口、12333/12345 咨询；补贴按季度或半年发放，注意申请时限（多为毕业后 2 年内首次申请）。
- 公积金租房提取：连续足额缴存、本人及配偶在当地无自有住房；额度与频次按城市（南京 2026 年单身约 21600 元/年、夫妻合计约 43200 元/年，按季度提取），材料为身份证、本人 I 类银行卡、婚姻状况信息，线上可办。

> 政策类内容时效性强，以上为 2026 年公开口径，办理前必须以提交当月官方公告为准。

## 起诉四件套（表格输出，缺一不可）

只要回答里出现「起诉/诉讼/立案」，必须按下面四行给全，且用表格，不接受散文：

| 项 | 必须写什么 | 依据 |
|---|---|---|
| 管辖法院 | 房屋所在地或被告住所地基层法院（写明哪个） | 民事诉讼法管辖规则 |
| 时效起算 | 3 年，从知道或应当知道权利受损及义务人之日起算；写明本案起算点 | 民法典 188 |
| 标的额与程序 | 金额 + 是否落在小额诉讼线（50% 以下 → 一审终审；50%–2 倍可约定） | 民诉法 165 条 |
| 证据清单 | 合同、转账、聊天记录、照片、备案信息等逐项列 | 举证责任 |

> 例：3000 元押金 → 管辖=房屋所在地基层法院；时效=2023-10 起算，未过 3 年；标的额 3000 元远低于本省 50% 线（多数省份 4–6 万元）→ 适用小额诉讼、一审终审；证据=合同+转账+催告聊天。
