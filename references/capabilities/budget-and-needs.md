# 预算与需求定位


## 必答要点（先看这 6 行）

- 先算可支配余额，再选房；房租上限见 affordability-model
- 同预算下优先级：通勤 > 治安 > 设施 > 面积 > 装修

> 回答末尾必须逐条复述以上要点（已覆盖 / 不适用+原因），缺一条视为未完成。

## R — 原文 (Reading)

> "一般来说，房租最好别超过你月收入的三分之一，这样才能保证你还有钱吃饭、穿衣、娱乐啥的。"
> — 《城市租房生存指南》§1.1.1

## I — 方法论骨架 (Interpretation)

租房决策的起点不是房源，而是钱与需求的约束条件。先把「每月能稳定拿出多少房租」算成一个硬上限（指南给的口径是税后月收入的三分之一），再用剩余约束倒推房型：单身一居、情侣两居、合租三居以上。同一笔预算下，四个维度互相挤占——通勤时间、面积与设施、独立卫浴/厨房、周边配套（超市、医院、治安）。正确做法是先把上限钉死，再按「通勤 > 安全与治安 > 基本设施 > 面积 > 装饰性条件」排优先级，最后才拿这份优先级去筛房。预算定高的代价不是当月多花钱，而是长期现金流紧张，遇到押金、搬家、维修等一次性支出时没有缓冲。

## A1 — 应用示例

### 示例 1：月入 12k 的应届生
- **类型与来源**：原书未提供完整案例，以下为按 §1.1.1–§1.1.5 规则做的合成演练。
- **输入**：税后月入 12,000 元；公司在市中心地铁沿线；一个人住；希望有独立卫浴。
- **方法论的使用**：上限 = 12,000 ÷ 3 = 4,000 元/月；一人住 → 一居或合租主卧；要独立卫浴 → 优先合租主卧独卫，其次老小区一居；通勤优先级高于面积。
- **结论**：预算区间 3,200–4,000 元，筛选条件写死为「地铁 40 分钟内 + 独立卫浴 + 押一付一或押一付三」。
- **结果**：合成演练，无现实成交结果；按原书规则可复算（三分之一上限）。

## A2 — 触发场景 (Future Trigger)

### 用户会在什么情境下需要这个 skill?

1. 刚拿到 offer / 刚毕业，第一次独立租房，不知道预算怎么定。
2. 在「贵一点但近」和「便宜但通勤一小时」之间纠结。
3. 在合租与整租之间摇摆，或被中介推荐了明显超出承受范围的房子。

### 语言信号

- "房租多少合适" / "房租占收入多少"
- "合租还是整租" / "预算 3000 能租到什么"
- "通勤一小时值不值" / "rent budget"

### 与相邻能力的区分

- 与 `sourcing-and-scam` 的区别：本卡只定预算与优先级，不判断房源真假。
- 与 `contract-review` 的区别：本卡在签约前，只产生筛选条件，不审条款。

## E — 可执行步骤 (Execution)

**必需输入**：税后月收入（元/月）、同住人数、通勤目的地与可接受单程时间、是否必须独立卫浴/厨房、是否接受合租。缺失收入或通勤目的地的，先问，不猜。

**交付物与完成标准**：一张「预算上限 + 优先级排序 + 筛选条件」三行结论，可直接拿去筛房源。

1. **算硬上限**
   - 完成标准：给出数字上限 = 月收入 ÷ 3（收入不稳定时按近 3 个月最低值算），并说明这是上限不是目标。
2. **排优先级**
   - 完成标准：把通勤、治安、设施、面积、装修五项排出顺序，且写明理由（哪项会天天影响生活）。
3. **映射房型**
   - 完成标准：给出 1–2 种可选形态（合租主卧独卫 / 一居 / 两居合租），每种标注预计价格带与牺牲项。
4. **产出筛选条件**
   - 完成标准：输出可直接搜索的条件串（区域/地铁线、价格上限、户型、押付方式、是否独卫）。
   - 判停条件：若上限低于该城市最低整租价，跳到第 3 步直接给合租方案，不再讨论整租。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 已经签完合同、进入纠纷阶段：预算不再是问题，直接用 `deposit-and-move-out` 或 `rights-and-benefits`。
- 买房、房贷与房产投资：不在本指南范围内。
- 单位/公司提供住房：预算约束失效，只需谈通勤与设施。

### 作者在书中警告的失败模式

- 为了面子租超预算的房子，导致「天天吃泡面」的现金流困境。
- 只看价格不看地段、交通、环境、设施，贪便宜吃大亏。

### 作者的盲点 / 时代局限

- 三分之一口径是经验值，未考虑一线城市合租市场与收入波动；高负债人群应按更低比例（如 1/4）执行。
- 未讨论房租年涨幅、押付方式（押一付三占用现金流）对预算的真实压力。

### 容易混淆的邻近方法论

- 与「记账/理财预算」不同：这里只做租房这一项的硬约束，不做全量收支规划。
