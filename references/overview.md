# 《城市租房生存指南》概览

## 主旨

把租房当成一条有明确阶段的工程流程来管理：租前（预算、找房、看房、签约）→ 租中（交接、清洁、开通、维护、沟通）→ 租后（退租、转租、维权），并在每个阶段用「证据 + 书面化」降低被坑概率。作者拿小多自称在 12 个城市租过房，内容来自经验总结而非学术研究。

## 骨架

1. **租前**：1.1 预算与需求（房租 ≤ 月收入 1/3、合租 vs 整租、通勤、设施、周边）；1.2 找房渠道与真假甄别（官方备案平台、社媒、中介；假房源/二房东/黑中介）；1.3 看房体检（小区、楼道、门窗水电、设施、费用、留证）；1.4 合同（身份核验、八项必备、五类高危条款、形式与谈判）。
2. **租中**：2.1 入住清洁；2.2 搬家与采购；2.3 宽带/水电燃气/物业/居住登记；2.4 日常维护、报修、房东与室友沟通、安全防范、维权入口。
3. **租后**：3.1 退租与押金；3.2 转租（房东同意、三方协议、交接）；3.3 经验总结。
4. **附录**：法律法规（民法典、城市居住房屋租赁管理办法）、常用表格模板（看房记录、合同、交接单、押金收据、水电记录、维修记录、退房通知、转租协议）、维权渠道（12315、房管局、12348、法院）、各城市租房补贴、公积金提取、居家安全装备。

## 关键口径

- 房租上限：月收入的三分之一（经验值）。
- 押付方式：常见押一付一、押一付三；押一付六需警惕现金流压力。
- 租期上限：民法典规定最长 20 年，续签后总期限仍不超过 20 年。
- 提前退租：按合同通知期，无约定时按 30 天。
- 转租：必须合同允许或房东书面同意，否则可能无效。
- 维权顺序：协商 → 社区调解 → 12315/房管/住建/12345/96119 → 12348 → 诉讼。

## 批判

- 内容是经验型指南，非法律或学术文本；法律条款只作提示，具体以现行法规与当地政策为准。
- 城市补贴、公积金、宽带资费等时效性强，必须现查。
- 未覆盖：租金贷与长租公寓爆雷、甲醛与室内空气、群租与隔断的合法性判断、房东失联的诉讼送达等进阶问题。
- 部分推荐商品与价格带会过时，只保留品类优先级。
